# firstmilemanager-help

First Mile Manager's help centre, at [help.firstmilemanager.co.uk](https://help.firstmilemanager.co.uk): how to do each task in First Mile Manager, what its messages mean and what its words mean.

It is a small Laravel app with Meilisearch search, copied from Stockist's help centre with Stockist's content taken out. Articles are Markdown in [`content/`](content/). [`AGENTS.md`](AGENTS.md) says how to build, run and check it, and [`docs/writing/style-guide.md`](docs/writing/style-guide.md) how to write help.

Brand: First Mile Manager's brand files are in [`brand/`](brand/README.md), copied from the marketing repository.
