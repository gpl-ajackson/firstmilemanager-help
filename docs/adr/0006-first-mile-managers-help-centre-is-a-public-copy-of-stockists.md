# First Mile Manager's help centre is a public copy of Stockist's, on the same server

First Mile Manager's help centre is a copy of Stockist's help centre app, with Stockist's content taken out and First Mile Manager's brand put in (decided on fmm#56, built by help#1). It keeps the same Articles, search, feedback, Launch Checks, Help Previews, Style Guide and Article Templates, so a writer or reviewer who knows one knows the other. After the copy the two are kept separately: a change to one is not copied to the other unless someone chooses to.

It differs from Stockist's in four ways:

- **Public from slice 0.** It is public and indexed from the start, with no gate, so it builds search ranking while it grows. An "early access" banner shows until alpha.
- **Shown once on the demo.** An Article goes public only once its feature reaches the demo, and a glossary term for something not built yet stays hidden.
- **Joint-only help.** Articles about Stockist are for readers at a Joint Operator and are hidden from readers at an FMM-only Operator, who never see Stockist's name.
- **Two glossaries.** The Glossary Check reads Stockist's `GLOSSARY.md` as well as First Mile Manager's, because Joint Operators meet both apps' words.

It runs on the same London server as Stockist's help centre, as a separate site with its own database and search index, apart from both apps (help#2). A fault on that server takes down both help centres; AJ accepted that to avoid a second server.

## Considered options

- **One help centre for both apps.** One place to search, but an FMM-only reader would meet Stockist's name and help everywhere, and each app's release would wait on the other's help.
- **A fresh help centre.** Free of Stockist's history, but it would rebuild search, feedback, checks and previews that already work.
- **Gated until launch, as Stockist's was.** Safer for half-written help, but it would start search ranking months later. Showing an Article only once its feature is on the demo gives the same safety.

Accepted by AJ on fmm#56, 13 November 2026.
